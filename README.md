## 📁 Consolidated Internship Projects

| Internship Directory | Focus | Key Projects |
| :--- | :--- | :--- |

---

## 🚀 Quick Start

### 1. Interactive Web Dashboard
Open [`index.html`](index.html) directly in any web browser to play Hangman and generate secure passwords live.

### 2. Command-Line Portfolio Runner
```bash
python main.py
```

### 3. Run Automated Tests
```bash
python -m unittest test_internships.py
```
